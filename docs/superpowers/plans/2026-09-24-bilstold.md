# Bilstöld Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser game in the style of GTA1/GTA2, called Bilstöld. The camera looks straight down on a city generated from a seed. The player steals cars, uses weapons and power-ups, runs from the police, deals with gangs and does payphone missions. Progress is saved in the browser.

**Architecture:** A headless, deterministic simulation (`src/sim`, `src/game`, `src/world`) runs at a fixed 60 Hz and imports no rendering or DOM code. A Canvas 2D renderer (`src/render`) draws that state into a low-resolution buffer, which is scaled up with pixelated filtering. WebAudio (`src/audio`) and the HUD react to events on a typed event bus. All art and sound are generated in code at startup.

**Tech Stack:** TypeScript 5 in strict mode, Vite 6 (dev and build only), Vitest 3 (tests), Canvas 2D, WebAudio, Gamepad API and localStorage. No runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-09-24-bilstold-design.md`

## Global Constraints

- The runtime has zero dependencies. `package.json` has `devDependencies` only (vite, typescript, vitest).
- There are no external asset files (images, audio, fonts). Everything is generated in code.
- The gzipped JS in `dist/` must be under 200 KB.
- Internal render buffer: 640 px wide, with height `round(640 / aspect)` clamped to the range 300–420. It is scaled to the window with CSS `image-rendering: pixelated`.
- The simulation runs at a fixed 60 Hz (`DT = 1/60`) with at most 5 steps per frame. The frame delta is clamped to 250 ms.
- Nothing is simulated or rendered while the tab is hidden. The AudioContext is suspended while the tab is hidden or the game is paused.
- Entity caps: 70 peds (the player included), 45 moving vehicles and 30 parked vehicles, at the same time.
- The city is 192×192 tiles. `TILE = 32` world units, and 1 world unit is 1 buffer pixel at zoom 1.
- The same seed string and city index always produce a byte-identical city. `Math.random` is forbidden in `src/world`, `src/sim` and `src/game`. Use `Rng` from `src/core/rng.ts`.
- The save key is `bilstold.save`, holding versioned JSON (`version: 1`).
- Traffic drives on the right (Swedish).
- UI text is in English. Vehicle and gang names have a Swedish flavor. No real brand names.
- Target browsers: current Chrome, Firefox and Safari on desktop.
- The simulation must never import from `src/render`, `src/audio`, `src/ui` or the DOM. This is enforced by the test `tests/arch.test.ts`.

## Review Focus

1. **Odd seed strings** such as `"  Bilstöld "`, `"🚗"`, `""` or a 500-character string. Seeds are NFC-normalized and trimmed before hashing. The same visible seed always gives the same city, and an empty seed means a random one. The test is in Task 1.
2. **Broken storage**, such as a corrupt, truncated or old-version save, or a `localStorage` that throws on access or when full (Safari private mode). The game must never crash. A corrupt save shows the title screen with the notice "Save was corrupt and has been discarded". Failed writes are silently ignored. The test is in Task 18.
3. **A tab left hidden for minutes, or a very slow frame.** The game must not fall into a catch-up spiral, and fast cars must not tunnel through walls (vehicle movement is substepped to at most 8 units per substep). The tests are in Task 2 (loop clamp) and Task 5 (tunneling).
4. **The player ending up inside a building or in water.** Places this can happen: respawn, exiting a car next to a wall, or loading a save. The player is always moved to the nearest walkable tile. The test is in Task 4 (`findWalkableNear`) and Task 18 (loading a save with a bad position).
5. **Input focus problems.**
   - Typing in the seed field must not produce game input.
   - Keys held while the window loses focus must be released on `blur`.
   - Unplugging a gamepad mid-game must release its axes.

   The test is in Task 3.

```ts
export type Rng = () => number;
export function normalizeSeed(s: string): string { return s.normalize('NFC').trim().replace(/\s+/g, ' ').slice(0, 64); }
export function hashString(s: string): number {           // FNV-1a over UTF-16 code units
  let h = 0x811c9dc5;
  for (let i = 0; i < s.length; i++) { h ^= s.charCodeAt(i); h = Math.imul(h, 0x01000193); }
  return h >>> 0;
}
function splitmix32(a: number) { return () => { a |= 0; a = (a + 0x9e3779b9) | 0; let t = a ^ (a >>> 16); t = Math.imul(t, 0x21f0aaad);
  t ^= t >>> 15; t = Math.imul(t, 0x735a2d97); return ((t ^= t >>> 15) >>> 0); }; }
export function makeRng(seed: number): Rng {               // sfc32 seeded via splitmix32
  const sm = splitmix32(seed); let a = sm(), b = sm(), c = sm(), d = sm();
  return () => { a |= 0; b |= 0; c |= 0; d |= 0; const t = (((a + b) | 0) + d) | 0; d = (d + 1) | 0;
    a = b ^ (b >>> 9); b = (c + (c << 3)) | 0; c = (c << 21) | (c >>> 11); c = (c + t) | 0; return (t >>> 0) / 4294967296; };
}
export function derive(seed: number, ...parts: (string | number)[]): number { return hashString(seed + ':' + parts.join(':')); }
export const randInt = (r: Rng, lo: number, hi: number) => lo + Math.floor(r() * (hi - lo + 1));
export const pick = <T>(r: Rng, a: readonly T[]): T => a[Math.floor(r() * a.length)];
export const chance = (r: Rng, p: number) => r() < p;
const W1 = ['RUSTIG', 'SNABB', 'BLANK', 'TYST', 'VILD', 'KALL', 'HET', 'GAMMAL', 'STOR', 'LILLA', 'MÖRK', 'GUL'];
const W2 = ['TRAKTOR', 'ÄLG', 'KORV', 'BIL', 'STAD', 'GATA', 'HAMN', 'BRO', 'TORG', 'KAFFE', 'LAMPA', 'VARG'];
export function randomSeedName(r: Rng): string { return `${pick(r, W1)}-${pick(r, W2)}-${randInt(r, 1000, 9999)}`; }
```

```ts
// loop.ts
import { DT, MAX_STEPS, MAX_FRAME_MS } from './const';
export class FixedLoop {
  acc = 0; alpha = 0;
  constructor(private step: (dt: number) => void) {}
  advance(frameMs: number): number {
    this.acc += Math.min(frameMs, MAX_FRAME_MS) / 1000; let n = 0;
    while (this.acc >= DT && n < MAX_STEPS) { this.step(DT); this.acc -= DT; n++; }
    if (n === MAX_STEPS && this.acc >= DT) this.acc = 0;           // drop backlog
    this.alpha = this.acc / DT; return n;
  }
}
export function startRaf(loop: FixedLoop, render: (a: number) => void, fpsCap: () => number) {
  let last = performance.now(), lastDraw = 0, id = 0;
  const frame = (t: number) => {
    id = requestAnimationFrame(frame);
    const cap = fpsCap(); if (cap < 60 && t - lastDraw < 1000 / cap - 1) return;
    lastDraw = t; loop.advance(t - last); last = t; render(loop.alpha);
  };
  id = requestAnimationFrame(frame);
  return { stop() { cancelAnimationFrame(id); } };
}
```

**Algorithm** (`generateCity`). Each step uses its own `makeRng(derive(seed, 'city', index, '<step>'))`.

1. **Base fill.** Fill `tiles` with `Grass` and pick `district` values.
   - Districts come from a Voronoi split over 14 random points.
   - The 3 points nearest the center become `Downtown`.
   - Points within 20 tiles of any coast edge become `Waterfront`.
   - The rest are weighted Residential 0.5, Industrial 0.3 and Park 0.2.
2. **Water.**
   - Pick 1–2 coast edges. The coast depth per row or column is a smoothed random walk within [3, 6].
   - With 60% chance, add a river: horizontal or vertical, 3–4 tiles wide, crossing the map. Its centerline moves ±1 every 8 tiles and is kept at least 30 tiles from the map edges.
3. **Road lines.** The ring road sits 8 tiles in from each edge.
   - Vertical roads: start at `x = 8`, then step `x += randInt(11, 16) + width` while `x < size - 8 - 14`, and finish with the ring road at `size - 10`.
   - Every third interior line is an **avenue** 4 tiles wide. The others are 2 tiles wide.
   - Horizontal roads are laid out the same way.
4. **Segment removal.**
   - Only interior, non-avenue lines are candidates. Each segment between two consecutive crossing lines is dropped with probability 0.15.
   - After each removal, BFS the segment graph for undirected connectivity. If the graph is disconnected, put the segment back.
5. **Paint lanes.** For each kept segment, paint from the first row or column of the start crossing through the last row or column of the end crossing.
   - Vertical: the left half of the columns gets `DIR.S` and the right half gets `DIR.N`.
   - Horizontal: the top half of the rows gets `DIR.W` and the bottom half gets `DIR.E`.
   - Set `tiles = Road` even over water; those tiles become bridges.
6. **Flag cleanup.** Clear any flag whose neighbor tile is not `Road`. Note: 2×2 intersections then allow a right turn at the near tile and a left turn at the far tile.
7. **Sidewalks.** Any non-road, non-water tile that is an 8-neighbor of a road becomes `Sidewalk`.
8. **Blocks.** Flood-fill the remaining `Grass` regions into blocks, then fill each by the district at its center.
   - **Downtown:** recursive bisection into lots (minimum 3×3). Each lot becomes `Building` with height `randInt(3, 6)`, or `Plaza` with 10% chance.
   - **Residential:** lots of 2–4 tiles. A building of height 1–2 is shrunk by 1 tile of grass garden, and each grass tile becomes a `Tree` with 20% chance.
   - **Industrial:** large lots. Buildings have height 1–3, with 25% `Parking`.
   - **Park:** grass, with trees at 15%. A plaza cross-path runs through the middle.
   - **Waterfront:** warehouses (height 1–2), `Parking` and `Plaza`.
9. **Outskirts and border.**
   - Land outside the ring road becomes Park-style forest (grass plus 35% trees).
   - The outermost ring of map tiles becomes `Tree`, except where it is water. This is a hard boundary.
10. **Gangs.**
    - Pick 3 gang centers from the non-Park district points, choosing them to maximize the minimum distance between them.
    - `gangZone[i]` is the nearest center (0..2).
    - `gangs[i] = { id: i, name: gangName(rng, i), color: GANG_COLORS[i], carModel: pick(rng, ['muscle', 'sports', 'pickup', 'van', 'sedan']) }`, with `GANG_COLORS = ['#e8c547', '#4fb3e8', '#d9534f']`.
11. **Landmarks.** `placeLandmarks(city, rng)` works as follows:
    - Candidates are `Sidewalk` tiles with a 4-neighbor `Road` and a 4-neighbor `Building`.
    - Counts: hospital 2, police 3, respray 3, bomb 1, crusher 1, garage 3, gangHQ 3 (one inside each gang's zone, with `gang` set), payphone 24 (4 per gang inside its zone with `gang` set, and 12 neutral).
    - Spacing: at least 30 tiles between landmarks of the same kind (payphones: 12), and at least 3 tiles between any two landmarks.
    - If spacing cannot be met, relax it by 25% and retry.
12. **Start point.** The start is the Sidewalk tile nearest the map center that is not a landmark.

**Physics** (`stepVehicle`):

- Split the velocity into forward and lateral components relative to `angle`.
- **Throttle** adds `accel·throttle·dt`, doubled while the car is still moving backwards.
- **Brake**: above +5 u/s it removes `2.2·accel·brake·dt`. Otherwise it reverses at `0.6·accel·brake·dt`, down to `-reverse`.
- **Drag**: `fwd *= 1 − 0.5·dt`, plus rolling friction of `60·dt` towards 0 when there is no throttle or brake.
- **Speed limit**: clamp to `maxSpeed`. The speed factor is `(health > 0 ? 1 : 0.3)`, and wrecks do not move.
- **Steering**:
  - Turn rate is `angVel = steer · turn · min(1, |fwd| / 120) · sign(fwd) · (handbrake ? 1.6 : 1)`, then `angle += angVel·dt`.
  - Tanks can turn in place: they use `max(0.5, …)` instead of the `min(…)` factor.
- **Grip**: `lat *= max(0, 1 − (handbrake ? 0.15 : 1)·grip·dt)`. If `|lat| > 70`, emit `skid` every 3rd tick.
- **Recompose** vx and vy from `fwd` and `lat` using the new heading.
- **Movement**: substeps `n = ceil(|v|·dt / MAX_SUBSTEP)`. In each substep, move by `v·dt/n` and then call `vehicleVsTiles`.
- **Water**: if the tile under the center is `Water`, then `sinking += dt` and velocity is multiplied by 0.9. At `sinking > 1.5`, set `wreck = true`. Occupants are killed later, in the World.

**Collision** (`collision.ts`):

- **`vehicleVsTiles(v, city, bus)`**
  - Sample 8 points: the 4 corners and 4 edge midpoints of the OBB.
  - For each point inside a solid tile, compute the smallest axis-aligned push out of that tile. Keep the largest push per axis.
  - Apply the push. Reflect the velocity component along the normal with restitution 0.3.
  - If the normal speed is above 90, emit `crash` with that force and call `damageVehicle(v, (vn − 90) · 0.12, null)`.
- **`resolveVehiclePair(a, b, bus)`**
  - Separate using `obbOverlap`, splitting the depth by inverse mass.
  - Apply the impulse `j = −(1 + 0.2)·vn / (1/ma + 1/mb)`.
  - If `|vn| > 70`, damage both vehicles by `(|vn| − 70)·0.1·(otherMass / myMass)^0.5`, set `lastHitBy` to the other driver, and emit `crash`.

  - `laneStep(w: World, v: Vehicle, random: boolean): { x: number; y: number }`, which returns the current aim point along the lane graph.
  - `obstacleAhead(w: World, v: Vehicle): Ped | Vehicle | null`
  - `pedAI(w: World, p: Ped, dt: number): void`. It dispatches `'wander'`, `'flee'` and `'idle'` here. The other modes are handled by later tasks through the `PED_AI` registry: `export const PED_AI: Partial<Record<PedMode, (w, p, dt) => void>>`. Later tasks register their handlers there.
  - `panic(w: World, x: number, y: number, r: number): void`, which makes the civilians within `r` flee from `(x, y)` for 4–8 s.
  - The `aiSystem` iterates over the active peds and vehicles. It skips the player, and skips vehicles whose driver is the player or that have no driver.
  - `spawnerSystem(w, dt)`: parked cars from Task 8, plus traffic and peds as described below.

**Lane following** (`laneStep`):
- When the vehicle's current tile index differs from `ai.lastTile`, choose a new `ai.dir`:
  - The candidates are the flags of the current tile, minus the opposite of the current direction.
  - An intersection tile has both a horizontal and a vertical flag. On leaving intersection tiles, `turnedHere` resets.
  - If `turnedHere` is set, only straight is allowed (when available). Otherwise straight has weight 3 and each turn has weight 1.
  - If `ai.dir` is not among the candidates, the car must turn.
  - Choosing a direction other than `ai.dir` sets `turnedHere = true`.
- The aim point is the center of the next tile in `ai.dir`.
- If the current tile is not a Road (a car pushed onto the sidewalk), aim at the nearest road tile within 3 tiles.

**Cruise:**
- Target speed is `min(0.45·maxSpeed, 190)`, dropping to 90 when `|angle to aim| > 0.4`.
- `obstacleAhead` looks for a vehicle or ped inside a cone in front of the car (dot > 0.75, distance < 40 + 0.3·speed + half the length). If there is one, brake fully.
- If blocked for more than 1.5 s, emit `horn` every 1.2 s. After 6 s, reverse for 1 s and then continue.

**Flee:** target speed is `maxSpeed`, with random turns and no stopping for peds.

**Traffic spawn:** every 0.25 s.
- If there are fewer moving vehicles than the target (24, or 30 downtown), pick a random Road tile at a distance in `[SPAWN_MIN, SPAWN_MAX]` from the player.
- The tile must have exactly one flag (not an intersection), and no vehicle may be within 70 u.
- The model is weighted by `weight` and the district: Industrial doubles truck and van, Downtown doubles taxi and sports, and Residential doubles compact and sedan.
- In a gang zone, 20% of spawns are the gang's `carModel` with a gang-member driver.
- The angle comes from the lane flag. `ai.mode = 'cruise'`, and the driver ped is spawned with `vehicle` set.
- Traffic is always spawned with ~40% of cruise speed so it does not start from 0 in view.

**Ped spawn:** a target of 40 peds (50 downtown, 25 in parks).
- Spawn on Sidewalk or Plaza tiles in the ring.
- Kinds: civ 80%, businessman 10% (downtown only, otherwise civ), elder 5%, criminal 5%.
- In a gang zone, 12% become gang members with `gang` set.

**Despawn:**
- Non-persistent peds and vehicles beyond `SIM_RADIUS` are removed. A vehicle's driver is removed with it.
- Corpses and wrecks are removed after 25 s if they are more than 450 u from the player.

**Ped wander:**
- Walk at 35 u/s in `ai.dir` along Sidewalk or Plaza tiles.
- If the next tile is solid or water, turn to a random valid direction.
- If the next tile is a Road: with 15% chance cross it, walking straight until the tile is non-road again. Otherwise turn.
- Every 0–6 s, randomly pause for 1 s.

**Ped flee:** run at 90 u/s away from `(ai.tx, ai.ty)`, avoiding solid tiles by trying ±45° and ±90°, until `ai.timer` runs out. Then return to wander.

**Panic sources:**
- The bus event `shot` (r = 220)
- `explosion` (r = 320)
- A vehicle moving faster than 120 u/s on a Sidewalk tile within 60 u. The ped dodges perpendicular to the vehicle for 0.4 s with 70% chance.

**Weapon behavior:**
- **Melee:** hit the first ped within `range` in a 60° front arc. `knocked = 0.4`. With the `electroFingers` power-up, it acts like `electro` instead.
- **Bullet:** spawns `pellets` projectiles with spread and `life = range / speed`. Each substep (≤ 8 u) tests solid tiles (the bullet dies), peds within 6 u other than the owner (damage, then the bullet dies), and vehicles (a point-in-OBB test: `damageVehicleBy`, then the bullet dies).
- **Arc:** instant. It hits the nearest ped in a 60° cone within range: `shocked = 1` plus damage, and it can chain to 1 more ped within 40 u.
- **Flame:** a short-lived projectile that passes through peds, damages them and sets `burning = 3` on them. Against vehicles it does 3 damage per hit, and it dies on the hit. Sustained flaming therefore sets cars alight through the normal health → burning path.
- **Thrown:** travels a parabola in 2D (it just slows down) and bounces off walls. When its life runs out: a grenade calls `explode` (Task 12) and a molotov calls `spawnFire` ×5 in a 24 u radius.
- **Rocket and shell:** explode on hitting anything or when their life runs out.
- **Drop** (car weapons): spawns a `Hazard` behind the car.
- **Bomb:** sets `v.bomb = 'timed'` and `bombTimer = 4`, and shows the message "Car bomb armed! Get out!".
- **Player firing** (in `controlPlayer`):
  - On foot, holding `fire` fires `ps.current`.
  - In a car, `fire` fires `v.carWeapon`. A tank uses `tankGun`, firing from the turret, which follows the car's heading.
  - `weaponNext` and `weaponPrev` cycle through the owned `FOOT_WEAPONS` whose ammo is above 0 (fists are always available).
  - The `fastReload` power-up halves the cooldowns.
  - `doubleDamage` doubles the damage from the player.
- **NPC firing:** uses `p.weapon` and `p.ammo`, where -1 means infinite, with a 1.6× cooldown multiplier (NPCs fire slower than the player).

    - Checkpoint races use 4–6 checkpoints and `timeLimit = distanceSum / 250 + 10`.

    | assassinate | The target is killed (by anyone) | The target escapes 800 u from its spawn in a car, or the timer runs out |

    | taxi | A passenger ped spawns at the phone and gets into the player's car within 30 u; drop it at the destination at speed below 30 | The passenger dies |
    | crush | A `crushed` event for the model | — |
    | rampage | Delegates to the frenzy | — |

    - The song is 32 bars. Its chord progression is 4 chords from `[[0, 3, 4, 5], [0, 5, 3, 4], [5, 3, 0, 4], [0, 4, 5, 3]]`, as scale degrees chosen by `songSeed`.
    - The bass plays the chord root on a station-specific pattern.
    - The lead is a 2-bar motif from a random walk over the scale, repeated with variation every 4 bars and resting in bars 0–1 of every 8 (intro feel).
    - The drums come from the pattern table.
  - **`class Radio`:**
    - `constructor(engine: AudioEngine)`
    - `setStation(i)`, `stop()`
    - `update()`, called at 10 Hz from `main`. It schedules the notes whose time falls within `currentTime + 0.25 s`, and moves to a new `songSeed` every 32 bars.
    - The drum synthesis: kick is a sine sweeping 120 → 45 Hz over 120 ms. Snare is noise with highpass 1500 over 120 ms. Hat is noise with highpass 7000 over 30 ms.
    - `name(): string`
  - Pressing `radio` (R) while in a car cycles `settings.station` modulo 5 and shows the station name in the HUD for 2 s. Entering a car starts the saved station. Exiting fades out over 0.3 s.
